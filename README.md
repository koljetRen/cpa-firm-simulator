# CPA Firm Simulator

A browser game where you build an accounting firm from a one-person practice toward the IPA 500: win clients, price services, hire staff, open offices, and acquire other firms month by month.

## Play

Open `index.html` in any modern browser — no build step or server needed.

To host it online, enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root). The game will be at `https://<username>.github.io/cpa-firm-simulator/`.

## Saving

Progress is saved in your browser's local storage on the device you play on. (The claude.ai-hosted version also syncs saves to your claude.ai account; that sync isn't available on other hosts.)

## Notes

- Single self-contained HTML file; fonts load from Google Fonts.
- Firm rankings are based on the 2026 IPA 500 revenue list.
